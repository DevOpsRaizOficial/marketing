    ## 0:25 — PONTO 1: Container vs VM (tabela) (1 min)

    Quando você ouve falar em container vs vm (tabela) pela primeira vez, parece complicado, mas tem uma analogia simples. Pensa numa entrega de pacote: cliente é quem pede, servidor é quem entrega. É só isso. Resumindo: container vs vm (tabela) é a base de toda comunicação que vai aparecer nas próximas aulas.
