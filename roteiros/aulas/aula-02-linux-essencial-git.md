    ## 0:25 — PONTO 1: Navegação: pwd, ls, cd (1 min)

    Quando você ouve falar em navegação: pwd, ls, cd pela primeira vez, parece complicado, mas tem uma analogia simples. Pensa numa entrega de pacote: cliente é quem pede, servidor é quem entrega. É só isso. Resumindo: navegação é a base de toda comunicação que vai aparecer nas próximas aulas.

    ## 1:25 — PONTO 2: Edição: cat, grep, nano (1 min)

    Esse é o ponto que mais derruba dev júnior em entrevista. Anota: edição: cat, grep, nano é o mecanismo por trás de tudo que funciona em rede. Sem isso, você não consegue chegar em nenhum site, app, ou API. Olha o comando que prova isso na sua máquina agora.

    ## 2:25 — PONTO 3: Git: init, add, commit, push (1m30s)
