LEGENDA (copia tudo abaixo):

Segredo: multi-stage build.

ANTES (errado):
FROM node:20
COPY . .
RUN npm install
RUN npm run build
CMD ["node", "dist/index.js"]
→ 1.2 GB (inclui source, node_modules dev, docs, etc)

DEPOIS (correto):
FROM node:20-alpine AS builder
COPY . .
RUN npm ci
RUN npm run build

FROM node:20-alpine AS production
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
CMD ["node", "dist/index.js"]
→ 150 MB (só o necessário pra rodar)

Benefício real:
→ Deploy 8x mais rápido
→ Imagem registry 8x mais barato
→ Superfície de ataque 80% menor
→ Pull no K8s mais rápido = escala mais rápida
