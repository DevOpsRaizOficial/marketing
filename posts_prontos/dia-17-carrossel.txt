LEGENDA (copia tudo abaixo):

Vou quebrar a arquitetura completa que construímos no Ebook 1:

FRONTEND (React + Vite + Tailwind)
↓ REST API HTTPS
BACKEND (Node.js + Express + TypeScript)
├─ Auth (JWT + Refresh Token)
├─ Cost Engine (agregações)
├─ AI Module (Claude/OpenAI)
├─ Alerts
└─ Reports
↓ Adapter Pattern ↓
AWS Cost Explorer / Azure Cost Mgmt / GCP Billing / OCI Usage
↓
PostgreSQL (Prisma ORM)
└─ users, credentials (encrypted AES-256-GCM), costs, alerts, ai_history

Por que Adapter Pattern?
Cada cloud tem API diferente. Adapter normaliza num schema comum.

Por que credenciais encriptadas?
AES-256-GCM no DB + chave em env. Se vazar o DB, credencial não vaza.

Por que Prisma?
Middleware injeta clientId automaticamente (Row-Level Isolation).
